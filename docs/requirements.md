# GCP (Game Coaching Platform) — 요구사항 명세서
## 사용자(학생) 기능 + 강사(코치) 기능

작성자: 18 장현제
작성일: 2026년 5월 8일

---

## 1. 서비스 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | Game Coaching Platform (GCP) |
| 한 줄 정의 | 게임 실력 향상을 원하는 학생과 코치를 연결해주는 게임 강의 매칭 웹 플랫폼 |
| 벤치마킹 | GIGS (op.gg) |
| 기술 스택 | React / Node.js+Express / MySQL |

---

## 2. 사용자 역할 정의

| 역할 | 설명 |
|------|------|
| 학생 (student) | 강의를 검색하고 결제·수강하는 사용자 |
| 코치 (coach) | 강의를 개설하고 수강자를 관리하는 사용자 |

---

## 3. 사용자(학생) 기능 요구사항

### 3.1 회원 인증

| ID | 기능 | 설명 | 수용 기준 (AC) |
|----|------|------|----------------|
| S-01 | 회원가입 | 이메일·닉네임·비밀번호·역할 선택으로 계정 생성 | 이메일 중복 시 필드 아래 에러 표시, 닉네임 중복 시 에러 표시, 가입 후 자동 로그인 |
| S-02 | 로그인 | 이메일·비밀번호로 로그인 후 JWT 토큰 발급 | 로그인 성공 시 token + user localStorage 저장, 비밀번호 오류 시 비밀번호 필드만 초기화 |
| S-03 | 아이디 저장 | 로그인 시 이메일 저장 체크박스 | 체크 시 localStorage에 이메일 저장, 다음 방문 시 자동 입력 |
| S-04 | 로그아웃 | Navbar에서 로그아웃 | localStorage token·user 제거, 메인으로 이동 |
| S-05 | 프로필 수정 | 닉네임·게임·티어·비밀번호·프로필 색상 수정 | 항목별 인라인 편집 방식, 본인 계정만 수정 가능 |

### 3.2 강의 탐색

| ID | 기능 | 설명 | 수용 기준 (AC) |
|----|------|------|----------------|
| S-06 | 강의 목록 조회 | 전체 강의 목록 확인 | 게임·티어·가격·코치유형 필터 동시 적용 가능 |
| S-07 | 강의 검색 | 강의 제목 또는 코치명으로 검색 | 실시간 필터링 |
| S-08 | 게임 카테고리 탭 | LOL·발로란트·TFT 등 게임별 필터 | 탭 클릭 시 해당 게임 강의만 표시 |

| S-10 | 정렬 | 랭킹순·평점순·가격순·최신순 | 드롭다운 선택 즉시 재정렬 |
| S-11 | 강의 상세 조회 | 강의 정보·코치·리뷰 확인 | 비로그인도 조회 가능, 최근 본 강의 localStorage 저장 |

## 4. 강사(코치) 기능 요구사항

### 4.1 회원 인증

| ID | 기능 | 설명 | 수용 기준 (AC) |
|----|------|------|----------------|
| C-01 | 회원가입 | 코치 역할 선택으로 계정 생성 | 학생과 동일한 가입 프로세스, role=coach |
| C-02 | 로그인 | JWT 토큰 발급 | 학생과 동일 |

### 4.2 강의 관리

| ID | 기능 | 설명 | 수용 기준 (AC) |
|----|------|------|----------------|
| C-03 | 강의 등록 | 제목·설명·게임·가격·대상티어·포지션·코치유형 입력 | 코치만 가능, coach_id는 JWT에서 자동 추출 |
| C-04 | 강의 수정 | 등록한 강의 내용 수정 | 본인 강의만 수정 가능 (서버 소유권 검증) |
| C-05 | 강의 삭제 | 등록한 강의 삭제 | 본인 강의만 삭제 가능 |
| C-06 | 내 강의 목록 | 본인 강의만 조회 | 다른 코치 강의 표시 안 됨 |

### 4.3 강의 콘텐츠 관리

| ID | 기능 | 설명 | 수용 기준 (AC) |
|----|------|------|----------------|
| C-07 | 강의 자료 등록 | YouTube URL 입력으로 콘텐츠 추가 | URL 입력 시 embed URL 자동 변환 |
| C-08 | 강의 자료 수정·삭제 | 콘텐츠 수정·순서 변경·삭제 | 본인 강의 콘텐츠만 관리 가능 |

### 4.4 수강자 관리

| ID | 기능 | 설명 | 수용 기준 (AC) |
|----|------|------|----------------|
| C-09 | 수강자 목록 조회 | 강의별 수강자 목록 확인 | 진도율·리뷰 작성 여부·성장 분석 여부 표시 |
| C-10 | 수강자 진도율 확인 | 수강자별 실시간 진도율 | 완료 콘텐츠 수 / 전체 콘텐츠 수, 퍼센트 막대 표시 |

### 4.5 성장 분석

| ID | 기능 | 설명 | 수용 기준 (AC) |
|----|------|------|----------------|
| C-11 | 성장 분석 작성 | 수강자 개인별 피드백 작성 | 본인 강의의 수강자에게만 작성 가능, 재작성 시 UPDATE |

## 6. 비기능 요구사항

| 항목 | 요구사항 |
|------|---------|
| 인증 | JWT Bearer 토큰, 유효기간 7일 |
| 권한 | RBAC — 학생/코치 역할 기반 접근 제어 |
| 보안 | bcrypt(salt=10) 비밀번호 해시, SQL Prepared Statement |
| 성능 | 강의 목록 DB 집계 쿼리 최적화 (JOIN + GROUP BY) |
| 테스트 | Playwright e2e 테스트 22개 통과 |
