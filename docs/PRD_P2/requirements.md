## 2. 사용자 역할 정의

| 역할 | 설명 | 주요 권한 |
|------|------|----------|

## 3. 유저 스토리 + 수용 기준 (AC)

### 3.1 인증

**US-01. 회원가입**
> 사용자로서 이메일/비밀번호로 회원가입하고 역할(학생/코치)을 선택하고 싶다.

AC:
- 이메일 중복 시 `EMAIL_DUPLICATE` 코드와 함께 409 반환
- 닉네임 중복 시 `NICKNAME_DUPLICATE` 코드와 함께 409 반환
- 비밀번호는 bcrypt(salt=10)로 해시 저장

**US-02. 로그인 및 토큰 발급**
> 사용자로서 로그인 후 JWT 토큰을 발급받아 인증된 API를 사용하고 싶다.

AC:
- 로그인 성공 시 `{ token, user }` 반환
- 토큰 유효기간 7일
- 잘못된 이메일/비밀번호 시 401 반환
- 프론트엔드에서 토큰을 localStorage에 저장하고 모든 요청에 자동 첨부

---

### 3.2 강의

**US-03. 강의 등록 (코치 전용)**
> 코치로서 강의를 등록하고 싶다.

AC:
- 비로그인 또는 학생 역할이면 401/403 반환
- coach_id는 JWT에서 자동 추출 (body 전달 불필요)
- 제목, 게임, 가격 필수 입력

**US-04. 강의 수정/삭제 (코치 본인 강의만)**
> 코치로서 본인이 등록한 강의만 수정/삭제하고 싶다.

AC:
- 다른 코치의 강의 수정/삭제 시도 시 403 반환

**US-05. 강의 목록/상세 조회 (공개)**
> 비로그인 사용자도 강의 목록과 상세를 볼 수 있다.

AC:
- 인증 없이 조회 가능
- 게임/티어/가격/키워드/정렬 필터 적용

---

### 3.3 결제 및 수강

**US-06. 강의 결제 (학생 전용)**
> 학생으로서 강의를 결제하면 즉시 수강이 시작됐으면 한다.

AC:
- 결제 완료 시 `status = 'approved'` 로 즉시 저장 (코치 승인 불필요)
- 본인 강의 결제 시도 시 403 반환
- 중복 결제 시도 시 409 반환
- 비로그인 시 결제 페이지 진입 불가

**US-07. 장바구니 (학생 전용)**
> 학생으로서 관심 강의를 장바구니에 담아두고 한 번에 결제하고 싶다.

AC:
- 장바구니 담기/제거/전체 비우기 가능
- 본인 강의 담기 방지
- 이미 수강 중인 강의 담기 방지
- Navbar에 수량 뱃지 표시

---

### 3.4 영상 진도율 / 이어보기

**US-08. 영상 이어보기**
> 학생으로서 영상을 중간에 끊고 다시 들어와도 이어서 볼 수 있었으면 한다.

AC:
- 재생 중 5초마다 진도 자동 저장
- 일시정지/종료 시 즉시 저장
- 다음 접속 시 마지막 시청 위치 -2초부터 재생
- 사이드바에 `▶ 3:24 이어보기` 표시
- 98% 이상 시청 시 완료 처리

**US-09. 강의 전체 진도율**
> 학생으로서 강의 전체를 얼마나 수강했는지 퍼센트로 보고 싶다.

AC:
- 실제 시청 시간 기반 퍼센트 계산 (영상 길이 가중치 적용)
- `20분 15초 / 30분` 형태로 시간 표시
- 60% 이상 시 리뷰 작성 가능

**US-10. 다음 강의 자동 이동**
> 학생으로서 영상을 다 보면 다음 강의로 넘어갈지 물어봤으면 한다.

AC:
- 완료 처리 시 다음 강의 모달 팝업
- 10초 카운트다운 후 자동 이동
- 머무르기 / 다음 강의 버튼

---

### 3.5 리뷰

**US-11. 리뷰 작성 조건 강화**
> 성의 없는 리뷰 방지를 위해 일정 수강 후에만 리뷰를 쓸 수 있게 하고 싶다.

AC:
- 수강 승인 상태 확인
- 강의 60% 이상 수강 후에만 작성 가능
- 미달 시 현재 진도율 안내 메시지 반환

---

### 3.6 성장 분석

**US-12. 코치가 성장 분석 작성**
> 코치로서 수강자에게 개인 피드백(성장 분석)을 작성해주고 싶다.

AC:
- 본인 강의의 수강자에게만 작성 가능
- 같은 학생에게 재작성 시 기존 내용 업데이트 (중복 생성 방지)
- 수강 승인된 학생에게만 작성 가능

**US-13. 학생이 성장 분석 열람**
> 학생으로서 코치가 작성한 성장 분석을 확인하고 싶다.

AC:
- 본인에게 작성된 분석만 열람 가능
- 목록 + 본문 형태로 표시

---

### 3.7 라우트 보호

**US-14. 프론트엔드 라우트 보호**
> 비로그인 또는 권한 없는 사용자가 보호된 페이지에 접근하면 적절히 차단됐으면 한다.

AC:
- PrivateRoute: 비로그인 시 /login 리다이렉트
- RoleRoute: 역할 불일치 시 / 리다이렉트
- 401 응답 시 자동 로그아웃 처리

---

## 4. 범위 정의

### MVP (완료)
- JWT 인증/인가
- 역할 기반 API 보호
- 결제 페이지 (자동 승인)
- 장바구니
- 영상 이어보기 + 진도율
- 성장 분석 (코치 작성 / 학생 열람)
- 다음 강의 자동 이동 모달

### 제외 (범위 축소)
- Refresh Token
- 실제 PG사 결제 연동 (Portone 등)
- AI 강의 추천
